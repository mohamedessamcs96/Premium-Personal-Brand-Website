# Personal Brand Website

My personal website: a single-page portfolio presenting my work as an engineer, researcher, educator and consultant.

## Sections

Hero · About · Portfolio · Articles · Courses · Workshops · Video series · Mentoring · Consulting · Contact

## Tech

React 19 · Vite · Tailwind CSS v4 · Framer Motion · TypeScript

## Run locally

```bash
pnpm install
pnpm dev        # start the dev server
pnpm build      # production build in dist/
```
